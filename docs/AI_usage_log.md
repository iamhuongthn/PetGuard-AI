# AI Usage Log

This document records the use of AI tools as reference and support resources during development of the PetGuard AI course project.

## Midterm - The Blueprint

### ChatGPT

ChatGPT was used as a supporting and reference tool during the Midterm project work.

AI assistance included:

- brainstorming and refining the project concept;
- reviewing project scope and feasibility;
- providing references and explanations for computer vision concepts;
- providing sample Python code and troubleshooting suggestions for reference;
- reviewing documentation for clarity and organization; and
- assisting with presentation visuals and wording.

All project decisions, implementation, testing, and submitted results were reviewed and verified by the team.
